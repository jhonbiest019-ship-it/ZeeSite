# B&M Stores - 100% Real-Time Live Sync & E-Commerce Clone

A high-fidelity, real-time live sync clone and enhanced e-commerce web platform inspired by [B&M Stores UK](https://www.bmstores.co.uk/).

## Features
- **100% Real-Time Live Sync**: Live reverse proxy engine streaming products, categories, search results, and deals directly from B&M Stores.
- **Full Product Catalog**: Pre-extracted 21 live trending & new arrival products with high-resolution photography, £ pricing, RRP savings, and badges (`products.json`).
- **Interactive Shopping Basket**: Real-time sliding cart drawer with quantity adjustments, free delivery threshold progress bar, and checkout preview.
- **Theme Switcher**:
  - Original B&M Stores (100% authentic visual match)
  - Royal Navy & Champagne Gold (Luxury palette with selective gold accents)
  - Forest Green & Warm Cream
  - Charcoal Black & Electric Blue
- **Live Search & Autocomplete**: Instant search across the B&M catalog.
- **Store Locator**: Search by UK towns, cities, or postcodes with opening hours and addresses.

## Quick Start
1. Double-click `start_website.bat` or run:
   ```powershell
   powershell -ExecutionPolicy Bypass -File .\server.ps1
   ```
2. Open your browser at:
   ```
   http://localhost:8080/
   ```
